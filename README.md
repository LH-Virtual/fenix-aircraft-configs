# Fenix Aircraft Configs

Livery configurations (`livery.cfg`, MSFS 2024) of the LH Virtual fleet for the Fenix A319/A320/A321.

One folder per fleet, inside it one folder per registration with its `livery.cfg`:

- `VL319` - Lufthansa City Airlines A319
- `LH319` - Lufthansa A319
- `LH320` - Lufthansa A320
- `4Y320` - Discover Airlines A320
- `LH321` - Lufthansa A321

## Tables

One overview per fleet with every registration and option. Registrations whose config differs from the rest of the fleet are marked with 🟧.

- [LH319](LH319/README.md) - Lufthansa A319
- [LH320](LH320/README.md) - Lufthansa A320
- [4Y320](4Y320/README.md) - Discover Airlines A320
- [LH321](LH321/README.md) - Lufthansa A321

The tables are generated by `tools/tabellen.py` on every push.
