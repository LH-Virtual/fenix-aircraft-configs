# Fenix Aircraft Configs

Lackierungs-Konfigurationen (`livery.cfg`, MSFS 2024) der LH-Virtual-Flotte fuer die Fenix A319/A320/A321.

Je Flotte ein Ordner, darin je Kennzeichen ein Ordner mit der `livery.cfg`:

- `VL319` - Lufthansa City Airlines A319
- `LH319` - Lufthansa A319
- `LH320` - Lufthansa A320
- `4Y320` - Discover Airlines A320
- `LH321` - Lufthansa A321

## Tabellen

Je Flotte eine Übersicht aller Kennzeichen und Optionen:

- [LH320](LH320/README.md) - Lufthansa A320
- [4Y320](4Y320/README.md) - Discover Airlines A320

Die Tabellen erzeugt `tools/tabellen.py` bei jedem Push automatisch.

## Download

- [LH320.zip](https://github.com/LH-Virtual/fenix-aircraft-configs/releases/latest/download/LH320.zip) - Lufthansa A320
- [4Y320.zip](https://github.com/LH-Virtual/fenix-aircraft-configs/releases/latest/download/4Y320.zip) - Discover Airlines A320

Die Zips werden bei jedem Push automatisch neu gebaut. Je Kennzeichen liegt ein Ordner mit der `livery.cfg` drin; die Datei ersetzt die `livery.cfg` im Ordner der jeweiligen Lackierung.

Optionen: https://support.fenixsim.com/hc/en-us/articles/12466593239567-Livery-Configuration-Options
